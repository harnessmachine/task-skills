# Task skills — цикл работы с задачами

Три скилла для рабочего штаба: `daily` помогает начать день, `retro` — разобрать неделю, `planning` — выбрать результаты следующей недели.

| Скилл | Когда использовать | Результат |
| --- | --- | --- |
| `daily` | В начале дня | Что ждёт тебя, фокус недели и одна задача для старта. Файлы не меняет. |
| `retro` | В конце недели | Срез по журналам задач, решения по незавершённому и HTML-отчёт. |
| `planning` | После принятого ретро | 1–3 результата следующей недели и HTML-план. |

## Что нужно до установки

Скиллы рассчитаны на [hq-starter v3](https://github.com/harnessmachine/hq-starter): `TASKS.md`, задачи в `tasks/<slug>/task.md` с журналом и скилл `manager`. Именно `manager` создаёт и обновляет задачи. Если у тебя другая структура, попроси агента сначала проверить совместимость и предложить адаптацию — не устанавливай вслепую.

## Установка

Открой свой штаб в Codex или Claude Code и отправь агенту:

```text
Установи в этот штаб скиллы daily, retro и planning из https://github.com/harnessmachine/task-skills.
Прочитай README репозитория и проверь, подходит ли мой штаб: TASKS.md, tasks/<slug>/task.md с журналом и скилл manager. Если структура отличается, сначала покажи, что нужно адаптировать. Не перезаписывай существующие одноимённые скиллы без моего согласия.
Скопируй папки skills/daily, skills/retro и skills/planning в .agents/skills/ моего штаба. Проверь, как в моей среде обнаруживаются скиллы; если нужно, предложи подключение для Claude Code. Затем проверь файлы и объясни, как вызвать daily в новом чате.
```

Начни с `daily`: попроси агента «запусти daily» или вызови `/daily`, если твоя среда поддерживает такую команду. В конце недели запусти `retro`, после принятого ретро — `planning`. Ретро требует записей в журналах за неделю и остановится, если их нет.

```text
daily → работа над задачей → manager записывает результат → retro → planning
```

HTML-отчёты сохраняются в `reports/`. Актуальное состояние остаётся в файлах задач. Прежде чем делиться отчётом, проверь его на личные данные.
