# Daily

Быстрый скилл штаба: владелец спрашивает — сразу получает ответ в чате. Daily открывает рабочий день, `retro` закрывает неделю, `planning` назначает следующую.

## Граница

Работай только с задачами этого штаба: `TASKS.md` и `tasks/<slug>/task.md`. Папки отделов, календарь, GitHub и внешние системы не читай. Ничего не меняй: в `TASKS.md` и `task.md` пишет только `manager`.

## Алгоритм

1. Определи сегодняшнюю дату из системного времени.
2. Прочитай `TASKS.md`.
3. Если в `reports/` есть план текущей недели `ГГГГ-WNN-plan.html`, прочитай из него выбранные результаты недели и их задачи.
4. Для каждой строки из «В работе» прочитай её `task.md`: `Статус:` и последнюю запись `## Журнал` (поля «Ждёт меня» и «Следующий шаг»).
5. Если статус в `TASKS.md` и `task.md` расходится или ссылка на `task.md` не открывается, покажи это как пробел записи. Не угадывай.
6. Распредели задачи ровно в один раздел:
   - `ждёт тебя` — статус `ждёт меня`; покажи, что именно нужно от владельца;
   - `в фокусе недели` — статус `в работе`, задача входит в план текущей недели;
   - `в работе` — остальные задачи со статусом `в работе`.
7. Задачи `готово` не показывай. Посчитай строки во «Входящих».
8. Предложи одну задачу, с которой начать: сначала то, что ждёт владельца и решается за минуты, затем фокус недели. Одна строка, без интервью.

## Формат ответа

```markdown
## Сегодня · ГГГГ-ММ-ДД

### Ждёт тебя
- <задача> — <что нужно от владельца> · tasks/<slug>/task.md

### В фокусе недели
- <задача> — <следующий шаг из журнала> · tasks/<slug>/task.md

### В работе
- <задача> — <следующий шаг из журнала> · tasks/<slug>/task.md

Входящие: N строк.
Начать с: <задача> — <почему одной фразой>. Скажи «продолжаем задачу <slug>».
```

Пустые разделы не показывай. Если активных задач нет: «Активных задач нет. Входящие: N строк — разобрать через `manager`?»

## Запрещено

- создавать отдельный список на день;
- менять статусы и журнал;
- скрывать задачи, которые ждут владельца;
- превращать ответ в ретро или планирование недели;
- задавать вопросы до первого ответа.
